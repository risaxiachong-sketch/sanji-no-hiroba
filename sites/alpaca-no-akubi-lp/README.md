# アルパカのあくび — Landing Page

宮崎県の子育て中の学生・保護者に向けた、オンライン子育て広場の紹介サイト。

- 配信: Sites
- 公開URL: https://alpaca-no-akubi.openvenus130.chatgpt.site/
- 構成: ビルド不要のHTML / CSS / JavaScript
- 公開ファイル: dist/
- アプリ: https://sanji-no-hiroba.vercel.app/
- ローカル確認: python3 -m http.server 4381 --directory dist --bind 127.0.0.1
- ホスティング設定: .openai/hosting.json

## 編集するファイル

- `dist/index.html`: ページ構成と文章
- `dist/styles.css`: デザインとスマホ対応
- `dist/script.js`: 動き・触れたときの反応・紹介動画・案内ダイアログの操作
- `dist/404.html`: 見つからないページの案内
- `dist/assets/soft/`: 公開用のWebP（画面幅ごとのサイズ違いを含む）
- `art/soft/`: 表紙の元画像と生成した水彩の挿絵（フルサイズの透過PNG、公開しない）
- `tools/make-images.py`: `art/soft/` から公開用WebP・共有カード・アイコンを書き出す
- `tools/subset-fonts.py`: 丸ゴシックを、ページで使う文字だけに絞って書き出す
- `ASSETS.md`: 画像の出典、保存先、生成時の最終プロンプト
- `MOTION_ASSETS.md`: 追加の生成画像とフォントの出典・ライセンス
- `FAQ_ASSETS.md`: Q&Aの読み聞かせアルパカの画像と生成プロンプト

このフォルダーに移動してローカル確認コマンドを実行すると、`http://127.0.0.1:4381/` で確認できます。表示にビルドやnpmパッケージは不要です。挿絵を差し替えたときと、新しい漢字・記号を文章に足したときだけ、`tools/` のスクリプトを実行し直します。

## デザイン方針

PowerPoint表紙の「あくびをするアルパカとカラフルなロゴ」をそのまま使用。雲や親子のアルパカ、水彩のまちの風景を大きく配置した、ふわふわとやさしい世界観を優先します。

四角い装飾枠、カードを並べる構成、濃い輪郭と硬い影、方眼背景、章番号や装飾用の英字ラベルは使用しません。本文は読める文字として残し、画像を囲う枠を増やさず、絵と余白でつなぎます。

ページ全体は「一日」の流れでつないでいます。朝の空の表紙 → ひろば（お昼） → まち（午後） → はじめかた（夕方の桃色） → 雲の上のQ&A → 星が瞬く夕暮れの「おやすみ」。場面と場面のあいだは、点線の小道が描かれていくことでつながります。

文字は太い丸ゴシックを同梱。絵ごとに異なる動きを付けています。

- 表紙：アルパカの呼吸。ときどき本当に「ふぁ〜」とあくびをします。なでる（マウスでなぞる、指で横になぞる）とハートがこぼれ、タップすると跳ねます。
- ひろば：アバターが小道を歩き、ふきだしでつぶやき、まわりから「わかるよ」などのリアクションが届きます。下のボタンで、見ている人もリアクションを送れます（紹介用の体験で、アプリには送信されません）。
- はじめかた：アバターの子たちにあいさつできます。PCでは2匹のアルパカが本文の横についてきます。
- 最後：夕暮れの空に星が瞬き、眠るアルパカから「z」が昇ります。

「うごきをおやすみ」で停止でき（選んだ状態はその端末に記憶）、端末の「視差効果を減らす」等の設定にも対応します。画面外の場面は動きを止めて、電池を使わないようにしています。挿絵は場面に入ったときに、読み込みを待ってからふわっと現れます。JavaScriptが無効でも、すべての文章と絵が表示されます。

スマホでは、最初のボタンが画面から消えたあと、下に「ひろばでひと息つく」が浮かびます（ほかのボタンが見えているあいだは隠れます）。動画・掲示板・案内は下から出るシートになり、上のつまみを下へ引くと閉じます。PCでは、上へスクロールすると見出しが戻り、いま読んでいる場所に印が付きます。

「はじめての方へ」は、親子のアルパカが絵本を読む雲の上のQ&A。最初の回答は開いた状態で表示し、ほかの質問もそれぞれ開閉できます。質問を開くとアルパカのひとことが変わり、挿絵も反応します。JavaScriptが無効でも質問・回答を読めます。雲や花の動きは最後の案内まで続きます。

Sitesで公開内容を更新するときは、`.openai/hosting.json` に記録した既存サイトを使います。GitHubへの保存とSitesでの公開更新は、それぞれ行います。

既存アプリの素材と開発版の紹介映像を使用。掲示板の例はサンプルであることを明示。
個人情報の入力フォーム・独自アクセス解析はありません。
